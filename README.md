# CV Website

My personal CV and portfolio website, showcasing my education, experience, technical skills, and software projects.

The website provides an online version of my CV alongside interactive examples of projects I have developed.

## Features

* Personal CV and profile
* Education and experience
* Technical skills
* Project portfolio
* Interactive projects
* Sailing and machine-learning projects
* Browser-based mini applications

## Projects

The website currently includes several interactive projects and demonstrations:

* **Calculator** — Browser-based calculator
* **Rock Paper Scissors** — Interactive implementation of the classic game
* **Todo List** — Browser-based task management application
* **SailingML** — Machine-learning project related to sailing
* **Projects** — Collection of larger software and machine-learning projects

## Technologies

The website is built using web technologies including:

* HTML
* CSS
* JavaScript

JavaScript is used for interactive components and project functionality, while CSS provides the website layout and styling.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/TobyStanislaus/tobystanislaus.github.io.git
cd tobystanislaus.github.io
```

The website is primarily client-side, so it can be run by opening `index.html` in a web browser.

For local development, a simple development server can also be used:

```bash
python -m http.server
```

Then open the local address provided by the server in a browser.

## Deployment

The repository uses the GitHub Pages naming convention:

```text
tobystanislaus.github.io
```

which allows the website to be hosted directly through GitHub Pages.

## Purpose

The website serves as an online portfolio alongside my traditional CV, providing a more interactive way to demonstrate my programming experience and projects.

It is intended to give recruiters and potential employers a quick overview of my technical background and provide direct access to examples of my work.
